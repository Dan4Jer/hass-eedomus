# Hass-Eedomus Commit Message Template
# Use this template for consistent commit messages

# Standard Format:
# <type>(<scope>): <subject>
# 
# <body (optional)>
# 
# <footer (optional)>

# Types:
# - feat: New feature
# - fix: Bug fix
# - docs: Documentation
# - style: Formatting (no code change)
# - refactor: Code refactoring
# - perf: Performance improvement
# - test: Test-related changes
# - chore: Maintenance tasks
# - revert: Revert a commit

# Scopes (for hass-eedomus):
# - Components: light, sensor, cover, switch, climate, binary_sensor, select, text_sensor
# - Modules: coordinator, entity, config_flow, options_flow, services, webhook, api_proxy
# - Core: const, manifest, __init__
# - Frontend: frontend, www, panel
# - Scripts: scripts
