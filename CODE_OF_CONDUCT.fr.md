# Code de conduite

Version courte : **sois respectueux et constructif**. Pas de harcèlement, pas de discrimination, pas d'attaques personnelles — dans les issues, les discussions, les pull requests, partout.

- Présume la bonne foi. On critique les idées, pas les personnes.
- L'anglais et le français sont tous deux les bienvenus ici. Le code, les logs et la documentation restent en anglais ; les traductions vivent dans les fichiers dédiés.
- En cas de désaccord, le mainteneur a le dernier mot.

Signalement : jdanoffre@gmail.com (objet `[conduct]`). Les signalements sont confidentiels.

Version longue : [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) (en anglais).
